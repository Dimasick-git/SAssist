# Android Client

## English — short guide

The Android app uses Kotlin, Jetpack Compose, Room, WorkManager, OkHttp and Coil. Build a debug APK with `./gradlew :app:assembleDebug`. The default public server is `wss://sassist-labs.onrender.com`.

For user installation, prefer the APK attached to the latest GitHub Release. The public Render server is a test service and may take time to wake after idle.

# Android-клиент — русская инструкция

## Сборка

Для локальной debug-сборки нужен Android SDK:

```bash
cd android
./gradlew :app:assembleDebug
```

Release APK собирается в GitHub Actions. Готовый файл находится в GitHub Release или в артефакте workflow **Android Build**.

## Первый запуск

Приложение по умолчанию подключается к `wss://sassist-labs.onrender.com`. При необходимости адрес можно изменить на экране входа: **Настройки сервера**.

Для локального backend используйте `ws://10.0.2.2:8080` в стандартном эмуляторе Android или `ws://<LAN-IP>:8080` на физическом телефоне.

## Офлайн-режим

История сообщений хранится в Room. Пока интернета нет, отправленные сообщения остаются с индикатором ожидания и автоматически повторяются после восстановления сети. WorkManager может закончить отправку в фоне. Сервер использует `clientId`, поэтому повторная попытка не должна создавать дубль.

## Медиа

Фото, видео, аудио и файлы ограничены 30 МБ на стороне сервера. Фото сжимаются до отправки, а обычные файлы и видео передаются бинарным потоком без base64. Процент рядом с кнопкой вложения показывает ход upload.

Видео открывается во встроенном проигрывателе; backend поддерживает Range-запросы. Файлы открываются через системный chooser Android, а не через серверное приложение.

## Bluetooth рядом

В списке каналов: **⋮ → Bluetooth рядом**. Включите режим на двух телефонах, подтвердите системные разрешения, найдите другое устройство и вручную подтвердите пару. Текст и файлы будут передаваться напрямую между устройствами. Эта функция работает только поблизости; она не заменяет интернет-сервер для удалённых пользователей.

## Звонки

В личном чате доступны кнопки аудио и видео. Разрешите микрофон и камеру, когда Android попросит. Для успешного вызова обоим участникам нужен интернет. При проблемах в закрытой корпоративной или мобильной сети может потребоваться TURN-релей на сервере.

## Приватность

Текстовые сообщения используют AES-256-GCM с ключом комнаты. Установите одинаковый ключ через значок **E2EE** на обоих устройствах. Фото, видео, файлы и offline Nearby-файлы не преобразуются в такой же формат E2EE; не отправляйте через публичный тестовый сервер чувствительные вложения.
