# SAssist v1.0.1

## English — short release notes

This maintenance update makes media and connection recovery clearer. Missing server attachments now show an explanatory state instead of an empty message bubble. The sender can post a new copy when the original is still available on their phone. Connection banners now explain a sleeping public server and provide a manual reconnect action.

## Русский — исправления maintenance-релиза

SAssist v1.0.1 устраняет две проблемы, заметные при ежедневном использовании приложения: недоступные вложения после перезапуска бесплатного сервера и непонятное ожидание подключения.

| Область | Что изменилось |
|---|---|
| Вложения | Если сервер больше не хранит файл и возвращает HTTP 404, вместо пустого синего блока показывается компактное сообщение **«Вложение недоступно»**. |
| Восстановление | Для своего файла, исходник которого ещё доступен на телефоне, можно нажать **«Отправить копию ещё раз»**. Будет создано новое сообщение с новой ссылкой на файл. |
| Очередь медиа | Неотправленное вложение показывает, что оно ждёт сети или не может быть отправлено. Пустые идентификаторы медиа больше не сохраняются как сообщения. |
| Подключение | Приложение объясняет, что бесплатному серверу после простоя может понадобиться до минуты на запуск, показывает причину ошибки и даёт кнопку **«Повторить»**. |
| Проверка | Release-сборка теперь также выполняет Android unit-тесты для логики восстановления вложений. |

## Установка

1. Скачайте `app-release.apk` из assets этого релиза.
2. Из-за временного ключа подписи сборок GitHub Actions перед установкой v1.0.1 может потребоваться удалить ранее установленный APK SAssist.
3. После установки войдите в приложение. Адрес публичного сервера по умолчанию: `wss://sassist-labs.onrender.com`.

## Важное ограничение

Файлы, которые уже были удалены перезапуском Render Free, нельзя восстановить с сервера. Новый вариант повторной отправки доступен только владельцу сообщения, если исходный файл всё ещё доступен локально на его устройстве. Не используйте публичный сервер как единственное хранилище важных файлов или переписки.

Полные инструкции находятся в [README.md](README.md).
