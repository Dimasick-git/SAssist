# SAssist v1.0.0

## English — short release notes

The first SAssist release includes real-time chat, profiles, offline message queue, nearby file sharing, private audio/video calls, and faster media transfer. The default public server is `wss://sassist-labs.onrender.com`.

## Русский — что входит в первый релиз

SAssist v1.0.0 — первый пользовательский выпуск Android-мессенджера.

| Раздел | Возможности |
|---|---|
| Чаты | Каналы `general`, `code-help`, `showtime`, личные сообщения, ответы, реакции, read receipts, typing и online status. |
| Профиль | Аватар, баннер, имя, `@username`, биография, цвет профиля и переход на публичный профиль из чата. |
| Офлайн | Локальная история Room, очередь сообщений, повторная отправка при появлении сети и синхронизация истории. |
| Медиа | Фото, видео, голосовые, файлы до 30 МБ; сжатие фотографий, потоковая отправка, видимый процент загрузки и быстрый старт видео. |
| Рядом без интернета | Прямая передача текста и файлов между сопряжёнными Nearby-устройствами; полученные файлы открываются системным выбором Android. |
| Звонки | Аудио и видео в личных чатах: входящий/исходящий вызов, принять, отклонить, микрофон, камера и завершение. |
| Приватность | Ключ комнаты E2EE для текстовых сообщений; signalling звонка в DM передаётся в зашифрованном payload. |
| Интерфейс | Русский язык установлен по умолчанию; English можно включить в **⋮ → Настройки → Язык интерфейса**. |

## Установка

1. Скачайте `app-release.apk` из assets этого релиза.
2. Разрешите установку из используемого браузера или файлового менеджера.
3. Если старый тестовый APK не обновляется, удалите его и установите этот APK заново.
4. Запустите приложение и войдите. Стандартный сервер: `wss://sassist-labs.onrender.com`.

## Важные ограничения

Публичный сервер работает на Render Free. После простоя он может просыпаться до минуты. Его файловая система не является постоянной: после restart или redeploy медиа и серверная SQLite-база могут сброситься. Не используйте этот endpoint как единственное хранилище важных файлов или переписки.

Bluetooth/Nearby работает между устройствами поблизости и требует ручного подтверждения пары на обоих телефонах. Для звонков нужен интернет; в отдельных мобильных и корпоративных сетях прямому WebRTC может понадобиться TURN-релей.

Полные инструкции находятся в [README.md](README.md).
